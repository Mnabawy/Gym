# Brainy
App name Brainy (expo `name` / `slug`; bundle id and scheme stay `gym`). Personal workout + nutrition app for one user. Arabic UI, RTL, Egyptian dialect copy.
Exercise names stay in English (gym vocabulary).

## Stack
- Expo SDK 58, TypeScript strict, expo-router (routes in `src/app/`, tabs in `src/app/(tabs)/`)
- State: zustand (`src/lib/timer.ts`, `src/lib/bus.ts`)
- Storage: expo-sqlite on iOS/Android (`src/lib/storage.ts`), localStorage on web (`src/lib/storage.web.ts`), same `Storage` interface
- react-native-health-connect (steps, Android), expo-build-properties (minSdk 26), expo-haptics, expo-keep-awake, expo-notifications (rest timer when backgrounded + workout reminder), expo-clipboard, expo-file-system + expo-sharing + expo-document-picker (backup file), expo-image-picker + expo-image-manipulator (progress photos), expo-local-authentication (app lock), expo-location (prayer times), react-native-webview (form videos play in-app; `YouTubePlayer.web.tsx` is a plain iframe), expo-intent-launcher (open other apps)
- Fonts: Apple's system font (SF Pro + SF Arabic on iPhone; sans-serif on Android): `F` + `font(w)` in `src/theme/index.ts` give fontFamily + fontWeight (+ tabular digits for `num*`); `T` uses it. Only Amiri Quran is loaded (verses)
- No backend. Offline-first.

## Design rules
- RTL forced (expo-localization plugin `forcesRTL` + I18nManager in root layout). Use `start/end`, never `left/right`.
- One fixed color per muscle (Okabe–Ito, colorblind-safe) in `src/theme/index.ts`.
- Technique tags: تقيل (filled), فشل (outlined), دروب (dashed). Copy in `src/data/rules.ts`.
- Food chip colors: protein blue, carbs orange, fat green, veg grey.
- Apple look app-wide: iOS system colors in `src/theme/index.ts` (grouped grey background, white cards, no shadows, hairline separators, system green switches, tinted/filled buttons, plain tint header icons), tight spacing (cards radius 12, page gap 8, rows 44pt). `warm` / `warmDark` are now the same as light/dark.
- App color: settings `accent` (default system blue `#007AFF`, `#0A84FF` in dark; settings `look` = 2 moved the old default red to blue once; #RRGGBB typed or a preset, `src/components/AccentPicker.tsx`); `useTheme` swaps in `accentTokens` (`src/lib/color.ts`: text color pushed to 4.5:1 contrast, readable text on buttons) for every theme incl. neon and warm
- Motion: react-native-reanimated + react-native-gesture-handler (`GestureHandlerRootView` in the root layout). `src/components/Motion.tsx`: `Item` (list item fades/slides in, fades out, the rest glides into place; used for tasks, subtasks, habits, goals, quits, road beads, meals, extras, shopping items, exercises, focus blocks, weights, hub rows), `Fade` (page content in `Screen`), `Press` (shrinks under the finger; `Btn` uses it), `Pop` (zooms in a checkmark). Don't use `withInitialValues` on entering animations (they stay hidden on web). Screens push iOS-style on both phones, swipe back from anywhere on iPhone. Reanimated follows Reduce Motion
- Swipe actions only on items that have real actions (`src/components/Swipe.tsx`, hand-built on gesture-handler v3 `usePanGesture` + reanimated; not ReanimatedSwipeable, which measured its panels wrong on Android RTL): `start` actions at the start/right edge (drag toward the left), `end` at the left edge; 72pt actions (narrower when a side has many, so an open panel covers at most 82% of the row and part of the row stays to tap or drag back), first one outermost; past half the panel it stays open, a full swipe runs the side's first action (only when that side's panel is under half the row); one row open at a time, tapping an open row closes it; iOS action colors `ACTION`; destructive ones undo or confirm. Used on tasks (خلصت / امسح, بكرة, عدّل), habits, goals and road beads, quits and slips, exercises and sets, meals, extras, supplements, shopping items, cardio, focus blocks, weights, program exercises. No swipe on rows whose only action would be «افتح» (hub, side menu, settings, reports). Modals need their own `GestureHandlerRootView` (`Sheet` has one)
- Light + dark from one token file. Segmented controls (MiniSwitch, the tasks tabs, calendar sources, focus kinds) use `t.segBar` / `t.segOn` (iOS: white on grey in light, #636366 on a grey track in dark). Touch targets ≥ 44pt.
- Small font app-wide: `T` (`src/components/ui.tsx`) draws every size × `TEXT_SCALE` (0.9). Write sizes at full scale; tight spacing (`Screen dense`) on the workout, food and shopping tabs.
- Every delete button is red: `Btn kind="danger"` (red on soft red; `dangerSolid` for the final wipe and danger confirms), trash/✕ icons in `t.bad`.
- Every `TextInput` style starts with `INPUT` (ui.tsx): on Android it drops the field's vertical padding and font padding, which cut Arabic text off while typing with the system font.
- One button size: `Btn` (40pt, one line of 14pt text that shrinks to fit) — use it for every text button. `T` caps the phone's font-size setting at ×1.15 (`maxFontSizeMultiplier`).
- Section colors `t.sec` (iOS system colors) only for small marks (icons, rings)
- The neon workout-tab mode was removed. `t.neon` now only means the bordered warm look (thin borders, `glow()`); the welcome screen and app lock use `warmDark`.
