# Brainy

تطبيق موبايل شخصي للتمرين والأكل. الواجهة عربي ومن اليمين للشمال. اتعمل بـ Expo وTypeScript.

## التابات
- **التمرين:** يوم النهارده، وتسجّل الوزن والتكرارات وتعلّم ✓ على كل مجموعة. أول ما تعلّم يشتغل عداد الراحة لوحده، والأرقام الباهتة جوه الخانات هي اللي لعبتها المرة اللي فاتت. ولو وصلت لأعلى عدد تكرارات في كل المجموعات، بيطلعلك «زوّد الوزن».
- **التقدم:** مجموعاتك في الأسبوع لكل عضلة قصاد الهدف (10)، ورسم بياني لكل تمرين.
  - **النواقص:** لوحة بتقولك إيه اللي ناقصك في آخر 4 أسابيع: الأيام اللي بتفوّتها، العضلات اللي مجموعاتها أقل من البرنامج (خريطة عضلة × أسبوع)، التمارين اللي بتتساب أو بتتلعب ناقصة، والتمارين الواقفة أو النازلة، وإمتى تاخد أسبوع خفيف.
  - **الكالندر:** كل يوم حضرت ولا فوّت ولا حضرت ناقص. تقدر تفلتر بعضلة، ودوس على أي يوم تشوف كل تمرين اتلعب منه كام مجموعة، واللي اتساب، والأرقام الجديدة.
- **الأكل:** أكل الأسبوع يوم بيوم، وتعلّم على كل وجبة كلتها، وفيه البدائل والمكملات.
- **المشتريات:** قايمة تعلّم عليها، وبتبدأ من جديد كل جمعة. وفيها زرار تنسخ بيه القايمة نص.

## التشغيل
```bash
npm install
npx expo start
```
امسح الـ QR code بتطبيق Expo Go، أو افتح المحاكي.

> اتجاه الواجهة من اليمين للشمال بيشتغل كامل في بناء التطبيق نفسه (development build أو EAS). Expo Go ممكن يتجاهله في أول فتحة، فلو حصل اقفل التطبيق وافتحه تاني.

## البناء على موبايلك
```bash
npm i -g eas-cli
eas login
eas build:configure
eas build --profile preview --platform android   # ملف APK تنزّله على الموبايل على طول
eas build --profile preview --platform ios       # للآيفون، محتاج حساب Apple Developer
```

## الأوامر
```bash
npm test            # اختبارات المنطق والبيانات
npm run typecheck
npx expo lint
```

## مهام جاية
- [ ] **إدخال البيانات بالذكاء الاصطناعي (مجاني):** تكتب أو تتكلم جملة عادية، والـ AI يطلّع منها البيانات ويحطها في القسم الصح.
  - الموديل: Gemini Flash-Lite (المجاني) بـ Function Calling، وGroq احتياطي لما الحد يخلص.
  - كل قسم يبقى tool (`log_set`، `log_meal`، `check_shopping_item`…) والتصنيفات والأسماء `enum` من بيانات التطبيق، علشان متتألّفش أسماء جديدة.
  - المفتاح يفضل في Supabase Edge Function، ومايتحطش جوه التطبيق.
  - الصوت: speech-to-text بتاع الموبايل (`expo-speech-recognition`).
  - كارت مراجعة يظهر قبل الحفظ، تأكد أو تعدّل منه.
